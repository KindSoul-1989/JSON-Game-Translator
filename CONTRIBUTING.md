# Contributing

Thanks for helping improve JSON Game Translator.

## Development

1. Fork the repository.
2. Create a branch for your change.
3. Make the smallest focused change possible.
4. Run the syntax check:

```bat
python -m py_compile json_translator_windows.py
```

5. Test the GUI on Windows when changing UI or API behavior.
6. Open a pull request with a short description of the change.

## Pull requests

Please avoid committing API keys, translated game files containing private material, checkpoint files, or generated build directories.

## Bug reports

Include Windows version, Python version (if running from source), application version, API provider/model, and the exact error message. Never include your API key.
