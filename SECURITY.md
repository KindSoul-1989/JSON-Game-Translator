# Security Policy

## Reporting a vulnerability

Please do not publish sensitive security details in a public issue. Contact the project maintainer privately through the repository's security contact or GitHub Security Advisories.

Never include API keys, credentials, private game files, or personal data in a report.

## API keys

API keys are entered locally and sent as an HTTP `Authorization: Bearer` header to the configured API URL. Users are responsible for protecting their keys and choosing a trusted API provider.
